# The Average Man: 1880 → 3070

A scrolling storytelling website that explores the evolution of music, technology, and everyday life across twelve generations, from 1880 to 3070.

Each generation represents a different era, featuring a unique character and a glimpse into how music and technology shape human life. The project combines historical inspiration with futuristic imagination using HTML and CSS.

### Built With
- HTML5
- CSS3
- Git and GitHub

**Goal:** To tell a visual story of how the world changes while the human connection to music remains.
